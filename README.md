## 🚀 Git Commands Reference

### 1. Initialize Local Git Repository
```bash
git init
```

### 2. Check Repository Status
```bash
git status
```

### 3. Stage Files
```bash
git add .
```

### 4. Commit Changes
```bash
git commit -m "Initial commit"
```

### 5. Link Local Repository to GitHub & Push
```bash
git branch -M main
git remote add origin https://github.com/swarnayashvanth73/myfirstgitproject.git
git push -u origin main
```

### 6. Pushing Subsequent Updates
```bash
git add .
git commit -m "Update personal details for Swarna Yashvanth"
git push
```
